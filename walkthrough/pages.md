# Pages, layers and find

- Each page of the file has a tab above the canvas. PageUp and PageDown move between pages.
- Layers lists the layers of the page with a check box each. A layer that is hidden in the file starts unchecked.
- Find searches labels, tooltips, links and custom data on every page. Enter jumps to the next match, Shift+Enter to the previous one. The match gets an orange frame and its details show on the right.
- Canvas: theme follows your color theme. Light and dark set the canvas for this tab.
